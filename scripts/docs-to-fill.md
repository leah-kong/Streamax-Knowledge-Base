# Docs to fill — product -> release notes & documents

为每个产品填：① 固件/工具发布（版本、发布说明、下载链接、校验码、大小、是否强制升级）；② 各类型手册（Datasheet / User Guide / Wiring Diagram / Certification）的 PDF 文件或外链。填好后发回给我，我用导入脚本批量生成 `manual` / `firmware` 条目。

字段说明：
- **Firmware/Tool**：`downloadUrl` 必填；`releaseNotes` 发布说明（西/英）；`checksum` 校验码；`fileSize` 大小；`mandatory` 是否强制升级(y/n)；`type`=firmware|tool。
- **Datasheet/User Guide/Wiring Diagram/Certification**：`fileEs`/`fileEn` 为西/英 PDF（放 `public/uploads` 或进 Git）；或 `externalUrl` 外链（二选一）；`title` 可留空（回退到产品名）。
